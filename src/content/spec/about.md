## 关于此站点

这是一个基于 [Fuwari](https://github.com/saicaca/fuwari) 模板构建的博客框架，使用 [Astro](https://astro.build) + [Svelte](https://svelte.dev) + [Tailwind CSS](https://tailwindcss.com) 构建。

::github{repo="saicaca/fuwari"}

### 技术栈

- **框架**: [Astro 5](https://astro.build) + [Svelte 5](https://svelte.dev)
- **样式**: [Tailwind CSS 3](https://tailwindcss.com) + [Stylus](https://stylus-lang.com/)
- **部署**: [Cloudflare Workers](https://workers.cloudflare.com/)
- **评论**: [Twikoo](https://twikoo.js.org/)

### 功能特性

- 浅色/深色/自动主题模式
- Material You 动态取色
- 搜索功能
- Markdown 扩展语法
- 代码高亮
- 图片灯箱
- 多语言支持

---

## 快速开始

1. 克隆仓库
2. 安装依赖：`pnpm install`
3. 复制配置文件：`cp src/config.example.ts src/config.ts`
4. 启动开发服务器：`pnpm run dev`

更多详情请查看 [README](https://github.com/Regex520/Masanori)。
